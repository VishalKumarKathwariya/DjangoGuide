Start Project Setup (Secure Django E-Commerce)

Create Root Folder
== E-Commerce Website

Open VS Code
== File → Open Folder → E-Commerce Website

Create Virtual Environment (Mandatory)
== python -m venv venv

Activate It
== venv\Scripts\activate (Windows)
== source venv/bin/activate (Mac/Linux)

Confirm Activation
== python --version

Upgrade Core Tools
== python -m pip install --upgrade pip setuptools wheel

Install Django (Controlled)
== pip install django

Verify Installation
== django-admin --version

Install Required Libraries
== pip install django pillow django-environ

Freeze Requirements
== pip freeze > requirements.txt

Start Django Project
== django-admin startproject project .   (Dot is IMPORTANT)

Run Server (Check Environment)
== python manage.py runserver
== CTRL + C (Stop Server)

Create .env File (IMPORTANT FOR SECURITY)

Location:
== Root Folder (Same as manage.py)

Example .env:

DEBUG=True
SECRET_KEY=django-insecure-change-this-key
ALLOWED_HOSTS=127.0.0.1,localhost

DB_NAME=ecommerce_db
DB_USER=postgres
DB_PASSWORD=yourpassword
DB_HOST=127.0.0.1
DB_PORT=5432

---

Configure .env in base.py

import environ
import os

BASE_DIR = os.path.dirname(os.path.dirname(os.path.dirname(os.path.abspath(**file**))))

env = environ.Env(DEBUG=(bool, False))
environ.Env.read_env(os.path.join(BASE_DIR, '.env'))

DEBUG = env('DEBUG')
SECRET_KEY = env('SECRET_KEY')
ALLOWED_HOSTS = env.list('ALLOWED_HOSTS')

---

Database Setup (PostgreSQL Recommended)

DATABASES = {
'default': {
'ENGINE': 'django.db.backends.postgresql',
'NAME': env('DB_NAME'),
'USER': env('DB_USER'),
'PASSWORD': env('DB_PASSWORD'),
'HOST': env('DB_HOST'),
'PORT': env('DB_PORT'),
}
}

IMPORTANT NOTES

1. NEVER commit .env file
2. ALWAYS use custom user model before first migration
3. KEEP dev and prod settings separate
4. USE PostgreSQL for production (not SQLite)
5. STATIC & MEDIA must be configured early
6. SECURITY settings should not be ignored
7. REQUIREMENTS.txt must be updated regularly
